## 🔍 What Is This Project?

**Disinfo Shield AI 2026** is an AI-powered system that:

1. **Detects fake/misleading content** using NLP pattern analysis
2. **Identifies coordinated campaigns** where multiple accounts push the same narrative
3. **Tracks cross-platform propagation** across 8 social networks
4. **Visualizes threat networks** with interactive force-directed graphs
5. **Provides analyst tools** for forensic investigation and reporting

It's designed for **journalists, fact-checkers, researchers, and security analysts** who need to identify coordinated disinformation operations.

## 📊 What Each Tab Does

The dashboard has **5 tabs** — here's what each one does:

### Tab 1: Multi-Platform Graph
An **interactive network visualization** showing how disinformation flows across platforms.

- **Hexagon nodes** = Campaign seed origins (the initial fabricated content)
- **Circle nodes** = Platform accounts that amplify the content
- **Edges** = Propagation paths between platforms
- **Click any node** → The right panel shows a forensic dossier (CIB score, platform, campaign, forward count)
- **Filter buttons** → Show only WhatsApp, Instagram, TikTok, Twitter, etc.
- **Recalculate** → Re-runs the force-directed physics layout

### Tab 2: AI Text Analyzer
Paste any text and get an instant **disinformation risk assessment**.

- Scores text on 4 dimensions: Sensationalism, Emotional Manipulation, Attribution Deficit, Cross-Platform Virality
- Detects **forensic indicators** like urgency anchors, authority name-dropping, censorship panic bait, WhatsApp forward signatures
- Has 6 pre-loaded samples including a **legitimate news baseline** to show the difference
- Three sensitivity modes: High Forensic, Strict, Permissive
- "Inject into Graph" button adds the analyzed text as a new node in the network

## 🧠 How the Backend Works

When you run the server (Method 3), the pipeline executes 3 stages:

```
Stage 1: COLLECT       Stage 2: CLASSIFY        Stage 3: CLUSTER
─────────────────      ─────────────────        ─────────────────
Twitter connector      For each post:           Group posts by
  → 8 tweets           "misinformation"         campaign keyword
Reddit connector         or "suspicious"        signatures (4
  → 6 posts              or "legitimate"        known archetypes)
                       + confidence score       + severity rating
```

All results are saved to a **SQLite database** at `data/disinfo.db`.

### API Endpoints

| Method | URL | What It Does |
|--------|-----|--------------|
| `GET /` | Serves the dashboard UI |
| `POST /ingest` | Submit a post for storage |
| `POST /analyze` | Run the full 3-stage pipeline |
| `GET /campaigns` | Get all detected campaigns |
| `GET /posts` | Get all stored posts |
| `GET /search?q=keyword` | Search posts by keyword |
